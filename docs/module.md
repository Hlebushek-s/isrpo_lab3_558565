# Module Session Timer

Плагин для CLion, который считает, сколько времени пользователь работает в проекте за одну сессию.

## Как это работает

1. При открытии проекта `SessionTimerActivity` создаёт сервис `SessionTimerService`, и отсчёт начинается.
2. Сервис раз в секунду добавляет время к счётчику активной работы. Если пользователь не делал действий дольше 5 минут, счётчик не растёт. Время, когда компьютер спал, не учитывается.
3. Окно Session Timer (`SessionTimerToolWindowFactory`) раз в секунду читает значения из сервиса и показывает их, а также список прошлых сессий.
4. При закрытии проекта `SessionTimerActivity` добавляет текущую сессию в список истории. Список сохраняется в `workspace.xml` проекта.

## Основные классы

| Класс | Назначение |
|-------|------------|
| `SessionTimerService` | Счётчики времени, определение простоя, хранение истории сессий |
| `SessionTimerActivity` | Запускает сервис сразу при открытии проекта и сохраняет сессию в историю при закрытии проекта  |
| `SessionTimerToolWindowFactory` | Строит окно с таймером и списком прошлых сессий |
