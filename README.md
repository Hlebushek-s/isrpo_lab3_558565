# Session Timer

Плагин для CLion, который считает, сколько времени вы работаете в проекте за одну сессию.

## Возможности

- Окно **Session Timer** на правой боковой панели.
- Активное время: если вы ничего не делаете в IDE больше 5 минут, отсчёт приостанавливается.
- Полное время с момента открытия проекта.
- Список прошлых сессий (последние 10), он сохраняется в проекте между запусками.

## Требования

- JDK 21
- Интернет при первой сборке (Gradle скачает зависимости и CLion 2025.2)

## Запуск и сборка

Запустить CLion с плагином для проверки:

```
./gradlew runIde
```

Собрать установочный архив:

```
./gradlew buildPlugin
```

Архив появится в `build/distributions`. Установить его можно через *Settings → Plugins → ⚙ → Install Plugin from Disk*.

## Документация

Документация по коду генерируется через Dokka:

```
./gradlew dokkaGeneratePublicationHtml
```

## Как устроен плагин

| Файл | Что делает |
|------|------------|
| `SessionTimerService.kt` | Считает время, определяет простой, хранит список сессий |
| `SessionTimerActivity.kt` | Запускает сервис при открытии проекта и сохраняет сессию при закрытии |
| `SessionTimerToolWindowFactory.kt` | Строит окно с таймером и списком прошлых сессий |

## Ограничения

- Если IDE закрылась аварийно, текущая сессия в историю не попадёт.
- Порог простоя (5 минут) и размер истории заданы константами в `SessionTimerService.kt`.
